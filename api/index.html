Open data API

Every ranking, review, score part and fact on this site as static JSON. No key, no sign-up, refreshed with the site twice a day.

Endpoints

Base URL https://archestack.com/api/v1/. All responses are JSON with version and license fields; browsers can call them directly (CORS open).

DocumentPathWhat it holds
Index/api/v1/index.jsonLists, categories with counts, alternatives, last update
List/api/v1/lists/{list}.jsonEvery category of a list with its top 5
Category/api/v1/categories/{list}/{category}.jsonEvery project in a category, ranked
Project/api/v1/projects/{list}/{project}.jsonScore parts, facts, license, links and the full review
Alternatives/api/v1/alternatives/{product}.jsonOpen-source picks for a paid product, by score
Schemas/api/v1/schema/{index|list|category|project|alternative}.jsonJSON Schema (draft 2020-12) of each document

Examples

curl -s https://archestack.com/api/v1/index.json | jq '.lists[].id'
curl -s https://archestack.com/api/v1/categories/best-of-ai/gateways.json | jq '.projects[:3] | map({name, score})'
curl -s https://archestack.com/api/v1/projects/best-of-ai/litellm.json | jq '{name, score, gpu: .facts.gpu, license: .facts.license}'

Ids are stable: {list}/{project}, the same as the page URL, and a renamed repository keeps its id.

The same data on GitHub

Each list's repository has every entry in one YAML file, data/entries.yaml: review text, specs, links, GitHub facts and score. The refresh rewrites it twice a day.

Terms

  • Data is CC BY 4.0: use it anywhere, including commercially, and credit Archestack with a link.
  • v1 only gains fields. Anything that would break a client ships as v2 next to it.
  • Every project document carries checked, the date of the GitHub data behind it.
  • Static files: no rate limit beyond GitHub Pages' own. Please cache for a few hours.
