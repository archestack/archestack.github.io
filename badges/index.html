Badges for maintainers

If your project is listed, you can show its place in your README. The badge updates with the rankings, twice a day.

What it shows

The project's place in its category and its score out of 100, the same numbers as on itsproject page.

Add it to your README

Your project page has the snippet with your own link, under "For maintainers". It looks like this:

[![Archestack](https://archestack.com/badge/mattpocock/skills.svg)](https://archestack.com/best-of-vibe-coding/projects/skills/)

Good to know

  • Free, with no sign-up. The badge is a static image served with the site.
  • A badge changes nothing in the ranking. Neither does removing it.
  • You can read everything we hold on your project in the list's data folder on GitHub, as YAML: Best of Vibe Coding (opens in a new tab) and Best of Open-Source AI (opens in a new tab).
  • Wrong fact or want out? Use the forms on GitHub (opens in a new tab); opt-outs are done within 24 hours.
