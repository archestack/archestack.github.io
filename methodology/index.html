How the ranking works

Every project gets a score out of 100 from public signals with published weights. The score sets the order; the review explains the project.

Signals and weights

A signal we cannot measure yet is left out and its weight goes to the others, so no project loses points for something we have not checked.

Penalties: no license −10, data must leave your host −10, star-growth anomaly −15, unpatched security advisory −20. Archived projects are removed. The weights are our judgment, not science.

Where the data comes from

  • Projects are found in curated lists, app stores and template galleries, then fact-checked on GitHub: stars, last commit, license, Docker files.
  • Each review is written from the project's own README and never copied from other lists: what it does, what it needs, and strengths and weaknesses you can check.
  • Reviews are rewritten when the README or the latest release changes. Projects with no commits for 12 months are marked stale, and archived ones drop off.
  • A project's own claim, such as "an alternative to Cursor" in its README, is labelled as its claim.

Independence

Nobody can pay for a place. Sponsors, affiliate links and tips, if any, are labelled and never touch the order. Archestack sells none of the tools it lists.

Corrections and opt-outs

Every list has forms on GitHub to add a project, fix a wrong fact or opt out (handled within 24 hours): open the forms (opens in a new tab). The full data is public under CC BY 4.0 at data.json and in each list's repository.
