How the ranking works

Checked on GitHub

Stars, last commit, releases, license and Docker files come from GitHub itself, not from the project's own claims.

Scored in the open

Each score is built from named signals with published weights. Every project page shows what its score is made of.

Nobody pays for a place

Sponsors and tips never move a rank. Spot a wrong fact and you can report it from any page.
